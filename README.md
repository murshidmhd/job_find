# NexTable | Premium Job Application Tracker

NexTable is a high-performance, glassmorphic data platform designed to streamline your job search. Built with pure HTML, CSS, and JavaScript, it offers a seamless experience for tracking cold emails and job applications.

## ✨ Features

- **Dual-Status Tracking**: Separate columns for "Cold Mail" and "Applied" status.
- **One-Click Toggles**: Instantly update your progress by clicking on status badges.
- **Job Apply Platforms**: Quick access to major job boards with original brand logos.
- **Smart Stats Dashboard**: Real-time overview of your application funnel.
- **Premium Glassmorphic UI**: Beautiful dark theme with smooth animations and micro-interactions.
- **Privacy First**: All data is stored locally in your browser (LocalStorage). No backend required.
- **Export to CSV**: Download your data anytime for use in Excel or Google Sheets.

## 🚀 Getting Started

1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. Use the integrated **NexBot** or the **Manual Add** button to start building your database.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure.
- **CSS3**: Custom glassmorphic design system using HSL colors and backdrop filters.
- **Vanilla JavaScript**: Dynamic UI logic, LocalStorage persistence, and CSV generation.
